# Hostel Complaint Management System

## 📖 Overview
The Hostel Complaint Management System is a Python-based application developed to simplify the process of registering and managing hostel complaints. It allows students to submit complaints and enables hostel administrators to monitor and resolve them efficiently.

## Features
- Student complaint registration
- View complaint details
- Complaint status tracking
- Hostel administrator management
- Simple and user-friendly interface

## 🛠️ Technologies Used
- Python
- Tkinter (GUI)
- SQLite (if used)
- File Handling

##  How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/anuradha302/hostel-complaint-management-system.git
   ```

2. Open the project folder.

3. Run the application:
   ```bash
   python acharya_hostel.py
   ```
